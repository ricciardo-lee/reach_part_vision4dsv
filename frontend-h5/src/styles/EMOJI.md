# Emoji 视觉规范（H5 / Admin 共用语义）

| 场景 | Emoji | 文案要求 |
|------|-------|----------|
| 拍照上传 | 📷 | 必须保留「拍照/上传」文字 |
| 开始识别 | 🚀 | 按钮文案不可仅图标 |
| 识别中/AI | 🤖 | 配合进度提示 |
| 品类候选 | 🧩 | 显示置信度百分比 |
| 车型 | 🚗 | 级联选择保留标签 |
| OE 号 | 🔢 / 🏷️ | OCR 结果需用户确认 |
| 产品结果 | 📦 | 展示匹配原因 |
| 成功 | ✅ / 🎉 | 与状态色一致 |
| 警告 | ⚠️ | 中置信度 |
| 失败 | ❌ / 🆘 | 提供补拍引导 |
| 空状态 | 📭 | 给出下一步操作 |
| 反馈 | 👍 / 👎 | 双按钮并列 |

原则：
1. Emoji 只做辅助，关键操作必须有文字标签。
2. 同一语义在 H5 与管理端保持一致。
3. 读屏依赖文字，不依赖 Emoji。
